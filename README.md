# 📊 Customer Churn Prediction Dashboard

An end-to-end Machine Learning project that predicts whether a telecom customer is likely to churn using customer demographics, service usage, and billing information. The project features an interactive Streamlit dashboard for real-time predictions and business insights.

---

## 🚀 Features

- End-to-end Machine Learning pipeline
- Data preprocessing and feature engineering
- Exploratory Data Analysis (EDA)
- Multiple model comparison and evaluation
- Logistic Regression-based churn prediction
- Interactive multi-page Streamlit dashboard
- Business insights with visual analytics
- Real-time customer churn prediction

---

## 🎯 Model

**Algorithm Used:** Logistic Regression

The model predicts customer churn based on features such as:

- Customer Demographics
- Service Subscription
- Contract Type
- Payment Method
- Monthly Charges
- Total Charges
- Customer Lifetime Value (CLTV)
- Tenure

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/Customer-Churn-Prediction.git
```

Move into the project folder

```bash
cd Customer-Churn-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
